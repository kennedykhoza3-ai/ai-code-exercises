# Learning a New Programming Language with AI

## Source and Target Languages

- Source Language: JavaScript
- Target Language: Java

## Part 1: Learning Goals

1. Learn Java syntax, variables, data types, and control structures.
2. Understand object-oriented programming in Java, including classes, objects, constructors, and methods.
3. Build a simple Java command-line application using the concepts I have learned.

## Part 2: Four-Step Prompting Strategy

### Step 1: Conceptual Understanding

I compared Java with JavaScript before writing code. I learned that Java is statically typed and requires more explicit structure, while JavaScript is dynamically typed and more flexible.

### Step 2: Step-by-Step Breakdown

I focused on Java classes and objects. I learned that a class acts as a blueprint and an object is an instance created from that class.

### Step 3: Guided Implementation

I created a `Student` class with fields for a student's name, ID, and course. I used a constructor to initialize the fields and created a `displayInfo()` method.

I then created a `Main` class, instantiated a `Student` object, and called the `displayInfo()` method.

### Step 4: Understanding Verification

I compiled and ran my Java implementation successfully. I reviewed the code for Java best practices and added a `getName()` getter to improve encapsulation.

The program produced:

`Student: Kennedy, ID: 1, Course: Software Development`

## Part 3: Advanced Prompting Techniques

### Technique 1: Using Context Effectively

I compared Java classes and objects with concepts I already knew from JavaScript. This helped me understand that both languages can use classes as blueprints for objects, but Java requires more explicit types and structure.

### Technique 2: Learning Through Teaching

I explained a Java class as a blueprint that describes what something should contain, while an object is an actual thing created from that class.

Explaining the concept in my own words helped identify a gap in my terminology. I initially described an object as being "modified" from a class, but learned that the correct concept is that an object is "created" or instantiated from a class.

### Key Learning

Connecting Java concepts to JavaScript and then explaining them in my own words helped me understand the concepts instead of simply memorizing Java syntax.

## Part 4: Mini-Project

### Project: Student Record Manager

I built a simple Java Student Record Manager using two files: `Student.java` and `Main.java`.

The `Student` class contains:

- A `name` field
- An `id` field
- A `course` field
- A constructor
- A `getName()` getter
- A `displayInfo()` method

The `Main` class creates a Student object and calls its `displayInfo()` method.

The final program output was:

`Student: Kennedy, ID: 1, Course: Software Development`

### Review and Refactoring

I reviewed the project for Java best practices. I kept the fields private and added a getter for the student's name to practise encapsulation. I also formatted the code and compiled it again to verify that the refactored version still worked.

## Reflection Questions

### 1. Which prompting strategy was most effective for your learning style?

Guided Implementation was the most effective for me because breaking the Java code into small steps helped me understand where each piece of code belongs and what it does.

### 2. What surprised you about the target language that wasn't immediately obvious?

I was surprised by how strict Java is about code structure, especially where fields, methods, and curly brackets must be placed. I also learned that Java requires types such as `String` and `int` to be declared explicitly.

### 3. How did your mental models from your source language help or hinder learning?

My JavaScript knowledge helped because I was already familiar with variables, objects, and functions or methods. However, Java was more challenging because it requires stricter types and class structure than JavaScript.

### 4. What would you do differently in your next learning session?

In my next learning session, I would work in smaller steps, test the code after each change, and make sure I understand where new code should be placed before adding it.

### 5. What gaps remain in your understanding of the target language?

I still need more practice with Java syntax, constructors, methods, getters and setters, and understanding how classes work together in larger programs. I also want to become more confident writing Java code without step-by-step guidance.
